# Практична робота №4

Гринишин Вікторія ІПЗс-24-2

Тема: Динамічна взаємодія з користувачем: маніпуляції з DOM, обробка подій та використання можливостей BOM у JavaScript

## Висновок

Під час виконання практичної роботи я закріпила навички створення інтерактивних вебсторінок за допомогою JavaScript. DOM (об’єктна модель документа) дає змогу знаходити HTML-елементи та змінювати їхній вміст і вигляд без перезавантаження сторінки. BOM (об’єктна модель браузера) забезпечує взаємодію з браузером і його вікном, наприклад, дає змогу отримувати інформацію про розмір вікна та реагувати на прокручування.

Також я навчилася обробляти події користувача, перевіряти дані форми, динамічно додавати відгуки та змінювати оформлення сторінки за допомогою CSS-класів. Отже, практична робота допомогла зрозуміти, як DOM, BOM і обробники подій використовуються для створення зручних та інтерактивних вебінтерфейсів.
